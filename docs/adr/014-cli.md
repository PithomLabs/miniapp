# ADR-014: One Lifecycle CLI Binary, Two Groups

Status: Adopted (surface frozen in Phase 0; see `docs/phase0/cli-spec.md`).

## Context

Separate invoke, deploy, and operate tools would fragment the operator
experience and duplicate policy.

## Decision

One `miniapp` binary with an invoke group (thin REST client) and a
lifecycle group. Every lifecycle command maps to exactly one lifecycle
stage, owns no policy, calls shared services, and never duplicates
`flyctl`, `psql`, or platform administration tools. New commands need
ADR notes.

## Consequences

- CLI/CI parity is structural: both call the same services.
- Command proposals outside the frozen surface are rejected by default.
